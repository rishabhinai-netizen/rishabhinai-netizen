## About

I sit at an unusual intersection — seven years of BFSI fraud investigation and forensic accounting on one side, and a habit of shipping production software on the other.

My day job involves dismantling financial crime across housing finance, banking, and NBFC portfolios. My nights involve building the analytical tools that should exist but don't — fraud detection systems, trading engines, regulatory dashboards, and fintech utilities that actually work in the Indian market.

Everything in this GitHub is a tool I built because I needed it, or because I saw a gap that a spreadsheet couldn't fill.
